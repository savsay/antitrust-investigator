# Kaynak metinleri (isteğe bağlı)

Bir kaynağın düz metnini buraya `<source_id>.txt` adıyla koyabilirsiniz (ör. `TR-01.txt`). Skill madde metni ararken önce bu klasöre bakar.

Eklemeden önce metnin yeniden kullanım hakkını kontrol edin. Kanun ve resmî karar metinleri genelde serbesttir; uluslararası kuruluş yayınlarının lisansı ayrıca okunmalıdır. PDF dosyalarını repoya koymayın; bağlantı `kaynaklar.csv` içinde durur.
